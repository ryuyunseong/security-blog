## 편집 및 검증

도입부, Markdown 목차, 표 제목과 코드 언어를 다듬었다. 최초 발행일을 유지하고 이전일을 별도로 표시한다. 코드 블록 95개는 순서·본문 해시로 대조했다. 원문 HTML·페이지 스크립트·쿠키·로컬 QA 자료는 저장소에 포함하지 않는다.

원문 작성 당시의 실습 기록은 원래 범위와 한계를 유지한다. 이번 이전에서 모든 Linux·제품 실습을 재실행한 것은 아니다. 새 블로그 글은 자체 canonical을 사용하고, 티스토리 원문을 출처와 구조화 데이터 isBasedOn으로 연결한다.
