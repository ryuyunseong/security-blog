# 화면 기준

## 참조

초기 홈 시안은 내장 Image Gen으로 생성했고, 저장소 밖 로컬 검토 자료로 보관한다.

생성 지시 요지: 한국어 보안 기술 블로그, 흰 배경, 숲색 강조, 카드 없는 구분선 글 목록, 오른쪽 카테고리·태그, 코드로 구현하는 텍스트 UI. 이미지 자체를 서비스 화면에 사용하지 않는다.

상세 시안도 같은 방식으로 생성했다. 생성 지시 요지: 같은 색·서체·헤더를 유지하고, 44px 제목, 출처 안내, 본문과 오른쪽 목차, 코드 복사, 관련 글을 배치한다. 실제 콘텐츠에 맞게 긴 본문은 자연스럽게 이어진다.

## 디자인 시스템과 구성 목록

- 배경: 순백 #ffffff, 본문 #17231e, 보조 #626e73, 강조 #22634d, 선 #e5e8e5. 그라데이션과 이미지 오버레이 없음.
- 글꼴: 한국어 시스템 sans-serif. 제목 44px/1.3, 글 제목 24px/1.45, 본문 16px/1.8, 메타 14px.
- 레이아웃: 최대 1220px, 데스크톱 홈은 본문과 280px 사이드바. 모바일은 한 열, 목록 이후 카테고리.
- 헤더: 텍스트 브랜드와 작은 코드 괄호 아이콘, 글 목록·카테고리·포트폴리오, 검색·테마 버튼. 선 아이콘은 24px, 두께 1.7, currentColor.
- 홈 문구: ‘읽고, 확인하고, 기록합니다.’, ‘Unix부터 웹·인프라 보안까지, 실습과 코드로 쌓아가는 기술 노트.’, ‘글 살펴보기’, ‘티스토리’, ‘최근 기록’, 실제 글 수, 예제 글 제목과 설명.
- 목록: 카테고리/예제 표시, 날짜, 제목, 설명, 태그, 화살표. 가로 구분선. 태그만 작은 테두리.
- 사이드바: ‘주제별로 읽기’, 5개 카테고리와 실제 개수, ‘태그’, 티스토리 안내.
- 푸터: 보안 노트, RSS, GitHub.
- 핵심 동작: 글 읽기 → 목차 이동·코드 복사·관련 글, 카테고리/태그 이동, 로컬 검색, 테마 저장.
- 추가 화면: 상세·카테고리·태그·검색·포트폴리오·404는 동일한 헤더·타이포그래피·구분선을 사용한다. 미정 개인 실적이나 외부 주소를 생성하지 않는다.
- 다크 모드는 요청 기능으로 추가하며 시안의 배치와 강조 계층을 유지한다.

## 의도적 조정

시안의 일부 잘못 렌더링된 한글, 실제 콘텐츠와 다른 태그/설명은 콘텐츠 계획의 정확한 문구로 교정한다. 모바일 메뉴는 줄 바꿈 가능한 간결한 내비게이션을 사용한다. 동작에 필요한 검색 입력, 목차, 코드 복사 버튼과 접근성 문구를 추가한다.

티스토리 이전 이후에는 실제 글·전체 태그, 원문·날짜 안내, 주통기 번호순 목차와 이전·다음 탐색을 반영했다. 320px 화면의 긴 한국어 제목은 단어 내부 줄 바꿈이 필요할 때 허용한다.
