# 화면 구성

흰 배경과 녹색 강조를 사용하는 한국어 기술 블로그입니다. 구현은 `src/styles/global.css`와 Astro 컴포넌트에 있습니다.

- 최대 폭 1330px. 작은 화면은 한 열이며 상세 화면은 본문과 목차로 구성됩니다.
- 카테고리·태그·시리즈·검색·RSS를 제공합니다. 글이 없는 점검 대상은 숨깁니다.
- 그림은 본문에 표시하며 모바일에는 세로 배치를 제공합니다.
- 긴 코드와 출력은 전체 내용을 펼쳐 읽을 수 있습니다.
- 테마 선택은 로컬에 저장합니다. 외부 글꼴·분석·추적 도구는 사용하지 않습니다.
- 본문 건너뛰기, 키보드 초점, 대체 텍스트와 줄어든 모션 설정을 지원합니다.
