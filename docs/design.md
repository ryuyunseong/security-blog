# 화면 기준

글과 코드가 먼저 읽히는 한국어 기술 블로그를 유지한다. 흰 배경과 숲색 강조, 구분선으로 나눈 글 목록을 사용한다.

- 기본 색: 배경 #ffffff, 본문 #17231e, 보조 #626e73, 강조 #22634d, 선 #e5e8e5.
- 서체: 한국어 시스템 글꼴. 데스크톱 제목 44px, 모바일 제목 32px. 본문과 코드의 줄 간격을 충분히 둔다.
- 배치: 최대 1330px 영역. 홈은 글 목록과 주제 탐색, 상세는 본문과 오른쪽 목차. 작은 화면에서는 한 열로 배치한다.
- 탐색: 홈 최근 8편과 페이지당 12편의 전체 글 목록을 구분한다. 카테고리·태그·시리즈·검색·RSS를 제공하고 포트폴리오는 하단에 둔다. 시리즈 번호와 글 수는 콘텐츠에서 계산한다. 모바일에는 홈 상단에 주제 링크를 두고 사이드바 태그는 자주 쓰는 12개와 전체 보기만 보여 준다. 공개 글이 없는 CVE는 노출하지 않는다.
- 그림: 내용에 맞는 도식을 본문에서 바로 읽는다. 대체 텍스트와 캡션을 제공하고 모바일에서는 큰 글씨의 세로 배치를 사용한다. 별도 보기 화면·확대 버튼·다운로드 안내는 두지 않는다.
- 실행 기록: 환경·실행 범위·명령·출력·종료 코드·해석을 함께 표시한다. 긴 출력은 펼쳐 읽고 코드는 가로 스크롤로 보존한다.
- 테마: 시스템 기본값과 사용자의 선택을 따른다. 선택은 로컬에 저장하며 분석·추적 도구나 외부 글꼴은 사용하지 않는다.
- 접근성: 본문 건너뛰기, 키보드 초점, 단일 h1, 이미지 크기 지정, 동작 상태 안내, 줄어든 모션 설정을 유지한다.

구현 기준은 src/styles/global.css와 각 Astro 컴포넌트다. 문서의 수치보다 실제 렌더링 결과를 우선 확인한다. 화면 변경 시 1440·390·320px와 다크 모드를 확인한다.
