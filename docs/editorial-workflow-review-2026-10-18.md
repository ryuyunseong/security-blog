# 신규 글의 그림 검토 절차 보완

2026-10-18, 작성 문서·템플릿·예약 지침을 같은 검토 순서로 연결했다.

## 변경

- `docs/article-media.md`: 그림과 캡션의 역할, 필수 조건 보존, 표현의 정확성, 코드·수치 대조, 화면 검토의 6단계와 편집 예시 3개를 추가했다.
- `templates/post.md`: 작성자용 검토 메모를 HTML 주석으로 추가했다. 공개 본문에는 표시하지 않으며 실제 그림 표식은 한 개다.
- `.github/prompts/daily-posts.md`: 생성 후 본문·노드·캡션을 함께 읽는 검토 단계를 추가했다.
- `README.md`: 글 작성 순서에서 검토 기준을 찾도록 연결했다.
- 로컬 예약: 같은 검토 절차를 반영했다. 이름과 본문 앞부분의 한글이 깨진 것을 발견해 저장소의 작성·발행 규칙으로 다시 정리했다. 정상 한글로 남아 있던 후반 지침은 원문 그대로 보존했다.

예약을 수정하기 전 원문은 Git 저장소 밖의 작업 자료 폴더에 보관했다. 수정 후 실제 설정을 다시 읽어 이름·본문의 정상 한글, 새 검토 지침, 기존 후반 지침 보존을 대조했다. 실행 시각은 한국 시간 매일 18:30이며 활성 상태·대상 채팅·생성 시각이 유지된 것도 확인했다.

## 검증

| 검사 | 결과 |
| --- | --- |
| `npm run check` | 45개 Astro 파일, 오류·경고·힌트 0개 |
| `npm test` | 기존 회귀 테스트 33개 통과 |
| `npm run build` | `/security-blog/` 경로로 116개 페이지 빌드 |
| `npm run verify` | 공개 글 25편, HTML 116개, 9,243개 검사 통과 |
| 작성 템플릿 렌더링 | 도식 표식 한 개, 작성자 검토 메모 비표시, `draft: true` 보존 |
| 기존 공개 자료 해시 | 글·그림·이전 그림 주소·검색·RSS·시리즈 103개가 편집 전 빌드와 일치 |

글·도식·스타일·실행 코드와 기록은 변경하지 않았다. 화면 자료의 해시가 같아 기존 공개 글의 브라우저 전체 검사는 다시 실행하지 않았다. 템플릿은 실제 Markdown 렌더러로 검토 메모의 비표시와 자료 배치를 검사했다.

## 범위와 후속 검토

인증·권한, 비밀 값, 입력 검증, 공개 로그에 영향을 주는 변경은 없다. 새 의존성이나 배포 설정도 추가하지 않았다. 문장 의미의 중복과 필수 조건 보존은 작성자가 본문·그림을 대조해 판단해야 하며, 체크리스트만으로 새 글의 품질을 보증하지 않는다.

이번 검증은 작성 절차와 예약 지침 반영을 다룬다. 다음 실제 글의 공식 근거·코드 실행·그림·화면·공개 반영은 해당 발행에서 독립적으로 검증한다. 클라우드 생성·발행 전환은 `docs/publishing.md`의 별도 작업으로 관리한다.
