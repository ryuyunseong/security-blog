# 콘텐츠와 공개 범위

2026-10-16에 사용자가 티스토리 글 이전과 공개 저장소 생성·커밋·푸시·GitHub Pages 배포를 승인했다.

## 이전 범위

최신 티스토리 홈과 사이트맵에서 공개 글 24편을 대조했다. 검색 서비스의 오래된 14편 캐시 대신 실제 공개 목록을 기준으로 삼았다.

- 주요정보통신기반시설 Unix U-01~U-10: 10편 전부 이전
- 파일·웹·TLS·압축 실습: 5편 이전
- 로그인 실패 집계·CIDR 알고리즘: 2편 이전
- Qualys 문서 해설: 4편 이전
- 보안 뉴스 1편, AI 도구 소개 2편: 이번 실습·점검 중심 이전에서 제외하고 원문에 유지

총 21편이다. [글별 이전 기록](migration.md)과 src/data/migration.json에 전체 24편의 결정을 남긴다. U-01~U-10 전부 이전은 티스토리에 현재 공개된 주통기 글 전체를 뜻하며, 가이드의 모든 Unix 항목을 작성했다는 뜻은 아니다.

## 편집 원칙

글마다 구체적인 상황으로 시작하고 확인할 질문으로 이어지도록 도입부를 다듬는다. 최초 발행일과 수정일을 유지한다. 사용자 후속 요청에 따라 사이트의 외부 블로그 연결·원문 안내·이전일·구조화 데이터의 출처 필드는 제거했다. 원문 코드 95개는 순서와 본문 해시로 대조한다. 이전 출처는 사이트에 배포되지 않는 개발 기록에만 남긴다.

17편의 코드를 Ubuntu 임시 파일과 루프백 환경에서 실행해 20개 기록을 남겼다. U-01은 별도 설정 해석만 수행했으며 전체 수집기나 실제 SSH 로그인은 시험하지 않았다. 각 글에 환경·범위·출력·종료 코드와 해석을 명시한다. Qualys 문서 해설을 실제 운영 경험으로 바꾸지 않는다. 실제 제품 접속·외부 스캔·기존 블로그 수정·삭제는 수행하지 않는다.

새 블로그의 글은 자체 canonical을 사용한다. 21편에 설명 도식을 넣고 학습 환경을 표현한 AI 생성 이미지 1개를 추가했다. 생성 이미지를 실습 증거나 제품 화면으로 표시하지 않는다.

## 구조와 공개 기준

홈·5개 카테고리·태그·검색·상세·포트폴리오·RSS·사이트맵·robots·404를 제공한다. 주통기 글은 번호순 목차와 이전·다음 글로 연결한다. 최초 교육용 예제 5편은 초안으로 보관한다.

원문 HTML, 로컬 QA 파일, 개발 환경 경로, 의존성·빌드 폴더와 자격 증명은 커밋하지 않는다. 공개 저장소에서는 초안 Markdown도 공개되므로 초안에 비밀을 넣지 않는다. 기존 티스토리와 다른 Pages 저장소의 설정은 변경하지 않는다.
