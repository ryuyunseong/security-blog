# 검증 및 인수인계

## 1. 변경 사항

- 공개 글 21편의 외부 블로그 원문·이전 안내, 홈·사이드바·포트폴리오 링크, sourceUrl/migrated 필드와 구조화 데이터의 isBasedOn을 제거했다. 최초 발행일과 수정일은 유지한다. 이전 출처 감사 기록은 배포되지 않는 migration.json과 개발 문서에만 남긴다.
- src/content/posts/의 공개 글 21편을 구체적인 상황과 확인할 질문으로 시작하도록 다듬었다. 원래 코드 블록 95개는 순서와 본문을 보존했다.
- ArticleVisual.astro, article-visuals.json과 public/assets/posts/에 주제별 SVG 21개와 AI 생성 학습 환경 이미지 1개를 추가했다. 그림의 대체 텍스트·크기·캡션·원본 보기와 사진의 생성 표시를 제공한다.
- ExecutionResults.astro와 executions.json/execution-context.json에 17편·20개 실제 실행 기록을 추가했다. 실행 환경·날짜·명령·범위·출력·종료 코드·해석을 함께 표시한다. 결과는 정적 HTML이므로 JavaScript 없이 읽힌다.
- scripts/run-article-examples.py로 Linux 임시 파일과 루프백만 사용하는 재현 절차를 보관한다. 코드 해시가 바뀌면 테스트에서 기존 결과의 갱신을 요구한다. Qualys 글 4편에는 제품 실행 결과를 표시하지 않는다.
- 의존성과 CI/CD 설정은 변경하지 않았다. 이미지 생성은 내장 image_gen을 사용했다. 최종 파일과 프롬프트는 article-media.md에 기록했다.

첫 브라우저 QA는 SVG를 단독 문서로 여는 검사에서 브라우저가 요청한 루트 /favicon.ico의 404를 사이트 오류와 함께 집계해 실패했다. URL을 추적한 뒤 사이트 동작과 SVG 조판 확인을 별도 페이지로 구분했다. 최종 사이트 동작 검사에서 콘솔 오류와 외부 자동 요청은 0건이었다. 동작 중 스크롤 화면을 찍는 문제는 QA의 reduced-motion 설정으로 제거했다.

공개 브라우저 검사 초안의 지원되지 않는 locator 보조 API는 표준 DOM 경계 확인으로 고쳐 재실행했다. 최종 검사는 통과했으며 사이트 코드 변경은 필요하지 않았다.

실행 범위는 다음과 같다.

- U-01: 운영 경로 고정 수집기 전체는 실행하지 않았다. 일회용 키·별도 설정의 sshd -T 해석에서 Match 조건 전후 no/yes를 확인했다. 데몬 시작이나 실제 SSH 로그인은 수행하지 않았다.
- U-02~U-10: 가상 설정·계정·그룹 파일의 수집/비교. PAM 인증·실제 잠금·중앙 계정 조회·계정 변경은 미실행.
- umask: 임시 Linux 파일의 생성 모드·기본 ACL·기존 권한 유지·자식 프로세스 상속 확인. 다른 계정의 실제 접근 시험은 미실행.
- TLS: 네 조건의 루프백 연결과 임시 인증서·키 정리. 외부 서버와 OS 신뢰 저장소 변경 없음.
- CORS: Python 클라이언트의 HTTP 응답 10조건. 브라우저 사전 요청과 응답 공개 시험은 미실행.
- 경로: 임시 파일/링크 비교 30건과 디코딩 2건. 파일 교체 경쟁 조건은 미검증.
- gzip: 한도·한도+1·잘림·추가 데이터·형식 등 9조건. 자원 공격 부하 시험은 미실행.
- 알고리즘: 로그인 실패 2,000개 무작위 비교, CIDR 400개 묶음 기준 풀이 비교와 경계/입출력 테스트.
- Qualys: 문서 해설만 제공. 제품 접속·API·실제 스캔은 미실행.

## 3. 보안/품질 검토

- 인증/권한 영향: 방문자 인증·상태 변경 API 없음. 운영 계정·PAM·SSH·신뢰 저장소와 배포 권한 변경 없음.
- 민감정보 영향: 가상 파일·계정·고정 실습 문자열만 사용. 원문 HTML·페이지 토큰·쿠키·비밀키·로컬 QA는 커밋 제외. 임시 인증서·키는 실습 종료 시 정리했다.
- 입력 검증 영향: 사이트 콘텐츠 스키마와 기존 검색 방식 유지. 코드 본문 95개는 변경하지 않았다. 결과와 캡션은 Astro의 텍스트 출력으로 표시한다.
- 로그 노출 가능성: 실제 시스템 로그 수집 없음. 출력은 생성한 시험 자료이며 임시 절대 경로만 $LAB으로 통일한다. 호스팅 서비스 자체의 로그 정책은 미확인.
- 기존 기능 회귀 가능성: 공개 글 수·시리즈 순서·내부 링크·원본 코드·검색·테마·복사·모바일을 검증했다. 모든 외부 참고 문서의 최신 내용 전수 감사는 미실행.
- 유지보수 리스크: 글의 코드 수정 시 결과 재실행 필요. 도식 데이터 변경 시 SVG 재생성 필요. 표현 이미지 약 1.9 MB는 지연 로딩한다. 제품 문서나 점검 기준이 달라지면 글도 재검토해야 한다.
