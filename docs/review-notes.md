# 검증 및 인수인계

## 변경 사항

2026년 10월 16일 글 두 편을 추가했다.

- `u-11-service-account-shell`: 2026 KISA 상세가이드 35쪽과 Linux 매뉴얼을 대조했다. 계정 용도, 제한용 셸, 빈 셸, 서비스 영향을 구분한다.
- `qualys-static-dynamic-tags`: VM/VMDR·GAV 공식 문서의 정적·동적 태그, 구독 조건, 재평가 상태를 설명한다. Python 비교는 제품 기능을 재현하지 않는 가상 자료 실습이다.
- 두 글에 SVG 도식과 개별 실행 날짜·환경·코드 해시·출력·검증 범위를 추가했다. 기존 글 21편의 날짜와 코드 95개는 유지했다.
- 클라우드 일일 발행을 별도 CI 작업으로 구성했다. 읽기 전용 생성, 공식 원문 대조, 별도 Docker 실행·검증, 허용 파일 발행과 명시적 Pages 배포로 나눴다. 공식 Unix 목록은 U-67까지이며 스키마 상한도 원문에 맞췄다.

화면 검사 첫 실행은 미리보기의 base 설정 누락으로 실패했다. 빌드와 같은 `/security-blog/` 경로로 다시 실행했다. SVG를 별도 문서로 열 때 브라우저가 요청한 루트 favicon 404는 실제 본문 안에 SVG를 삽입해 경계를 측정하도록 검사 방식을 고쳐 구분했다. 본문 화면은 콘솔 오류 없이 통과했다. 도식의 데스크톱·모바일 캡처도 확인했다.

별도 린트 명령은 정의돼 있지 않다. 운영 계정 변경·로그인 차단 시험, 실제 Qualys 접속·API·스캔은 수행하지 않았다.

첫 클라우드 verify 실행(38907183636)은 공식 PDF 확인 단계에서 실패했다. 같은 공식 URL에 curl은 HTTP 400, Node 기본 HTTP 클라이언트는 PDF 200을 반환하는 차이를 재현했다. 다운로드를 Node fetch로 바꾸고 TLS·리디렉션 거부·16 MiB 상한·PDF 형식·원문 해시 검사는 유지했다. 수정 후 38907665448에서 통과했다. 로컬 Python에는 PyYAML이 없어 YAML 확인을 실행하지 못했으며, 이미 설치된 Node yaml 파서의 중복 키·구문 검사로 두 워크플로를 확인했다.

클라우드 격리 시험 환경은 Debian 13 Docker, Python 3.12.15다. 오늘 글에 저장한 WSL/Python 3.12.3 실행 기록과 구분하며 기존 기록은 변경하지 않는다. 후속 검증에는 U-11 본문 코드의 실제 읽기 전용 마운트·실행·출력 대조도 포함했다. 실제 API 생성과 생성 결과의 발행 전체 경로는 아직 검증하지 못했다.

## 보안·품질 검토

- 인증/권한 영향: 사이트 인증·권한 변경 없음. 실습은 운영 계정에 접근하지 않는다.
- 클라우드 권한: 작성 단계 contents:read와 :read-only, 발행 단계에만 contents:write. API Secret은 공식 작성 Action에만 전달하며 실행·발행 작업에 넘기지 않는다. Pages 작업은 contents:read·pages:write·id-token:write를 사용한다.
- 민감정보 영향: 코드 안의 가상 계정·자산만 사용한다. 비밀번호·GECOS·실제 호스트 정보는 출력하지 않는다.
- 입력 검증 영향: 형식 오류·중복·필수 자료 누락을 별도로 확인한다. 이 예제의 허용 형식을 실제 Unix 전체 형식이나 Qualys API 스키마로 해석하지 않는다.
- 로그 노출 가능성: 공개하는 출력은 가상 자료뿐이다. 기존 기록의 날짜·환경·출력은 변경하지 않았다.
- 기존 기능 회귀 가능성: 기존 21편·코드 95개 보존, 검색·RSS·목차·페이지 링크를 검사했다.
- 유지보수 리스크: 제품 문서는 앱·구독·릴리스에 따라 달라질 수 있다. 셸 문자열 비교만으로 실제 로그인 제한이나 서버 양호를 확정하지 않는다. 자동 검사는 문장별 사실 판단을 대신하지 않으며 의미상 중복·모델 기본값·API 비용 변화도 검토해야 한다.

## 현재 상태

- 진행률: 전체 요청 임시 85%. 오늘 두 글의 공개 배포, 클라우드 공식 원문·격리·회귀·화면 검사를 확인했다. 실제 API 생성·발행과 예약 활성화를 남겼다.
- 완료된 작업: 두 글, 공식 자료 대조, 실제 예제 실행, 도식, 빌드·화면 검증, 일반 커밋 8eba900, Pages Actions 38904977669 성공과 공개 HTTP 200.
- 남은 작업: API 키 등록, 생성 preview 및 실제 발행 경로 확인, 활성화와 기존 로컬 예약 중지.
- 현재 차단 요소: OpenAI Platform 연결의 OAuth 재인증 오류. API 키는 생성·등록되지 않았다. 기존 로컬 예약은 PC가 켜져 있어야 하며 클라우드 예약 완료로 볼 수 없다.
