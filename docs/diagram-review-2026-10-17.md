# 그림 문구 정리와 발행 전 검증

2026-10-17, 공개 글 25편의 그림과 앞뒤 본문·캡션을 대조했다.

## 변경

- 그림 안의 전체 제목·브랜드·하단 설명을 덜고 노드·조건·수치·관계는 보존했다. 제목은 대체 텍스트와 SVG title, 보충 설명은 SVG desc에 남겼다.
- 시간축의 조건값과 경계, 주소 구간의 축·양 끝 포함 여부, 센서 통신 방향, 가상 자산·Bash 실습 범위를 필요한 캡션에서 읽을 수 있게 했다. 캡션 9개를 편집했다.
- 데스크톱은 10가지 형식별 도식 영역을 사용하고 HTML 이미지 높이를 함께 계산한다. 모바일은 큰 글씨를 유지하며 원본·모바일 SVG 50개를 재생성했다. 모바일 SVG 높이는 22~38% 줄었다.
- 작성 문서와 클라우드 작성 프롬프트에 중복 편집 기준을 반영했다. 로컬 예약에도 같은 기준을 추가하고 기존 시각·활성 상태·대상 채팅·이전 지침 보존을 대조했다.
- 글 Markdown, 발행일, 노드 데이터, 사진, 실행 기록·환경·코드 해시는 바꾸지 않았다. 예제 코드를 이번 편집에서 재실행한 것으로 표시하지 않는다.

## 검증

| 검사 | 결과 |
| --- | --- |
| `node scripts/build-article-diagrams.mjs` | 25편의 원본·모바일 SVG 50개 생성, XML 파싱 통과 |
| `npm run check` | Astro 45개 파일, 오류·경고·힌트 0개 |
| `npm test` | 33개 통과. 노드 보존, 반복 제목·주석의 비표시, 메타데이터·XML 이스케이프·기존 코드와 실행 기록 일치 검사 |
| `npm run build` | Pages의 `/security-blog/` 경로, 116개 페이지 빌드 |
| `npm run verify` | 공개 글 25편, HTML 116개, 링크·앵커·이미지 크기·검색·RSS·사이트맵 등 9,243개 검사 통과 |
| `BLOG_QA_ALL=1 node scripts/verify-daily-browser.mjs` | 전체 25편, 1440·767·390·320px에서 204개 검사 통과, 콘솔 오류 0개 |
| JavaScript 없는 Chromium | 흐름·구간·분기 그림 3편을 320·767·1440px에서 검사, 9개 통과 |
| 직접 화면 검토 | 모바일 4편과 데스크톱 4편의 그림·캡션 캡처 검토 |

화면 검사는 실제 표시 글자 크기, 텍스트·도형 경계, 글자 겹침, 이미지 높이·캡션, 코드·출력 전체 내용, 접기·펼치기, 가로 넘침과 이전 그림 주소의 본문 앵커 이동을 포함한다. 첫 실행에서 합류 도식의 빈 text 요소가 경계 밖으로 측정됐다. 빈 요소를 생성하지 않도록 고치고 전체 204개 검사를 다시 통과했다. 경계 검사는 원점이 다른 viewBox에도 적용하고 도형 잘림 검사도 추가했다.

## 보안·품질과 범위

- 인증/권한 영향: 해당 없음. 배포·예약의 권한이나 활성화 조건을 변경하지 않았다.
- 민감정보 영향: 해당 없음. 새 계정·자격 증명·운영 자료를 수집하지 않았다.
- 입력 검증 영향: 기존 노드·구간 검증과 XML 이스케이프를 유지했다.
- 로그 노출 가능성: 새 공개 로그 없음. 기존 실행 기록은 원본과 같다.
- 기존 기능 회귀 가능성: 위 전체 화면·빌드 검사로 본문·자료·검색·RSS·시리즈·이전 주소 호환을 대조했다.
- 유지보수 리스크: 새 형식이나 노드 배치를 바꾸면 도식 영역과 이미지 크기를 함께 검토해야 한다. 실제 Android·iOS 기기는 검사하지 않았으며 화면 검증은 Windows Chromium 기준이다.

이 기록은 발행 전 로컬 검증 결과다. 일반 커밋·푸시 후 Pages Actions와 공개 글·그림·RSS·시리즈의 실제 반영을 별도로 확인한다. 클라우드 API 생성·발행 활성화는 이번 작업 범위에 포함하지 않는다.
