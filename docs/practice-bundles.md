# 글별 실습 ZIP

`public/downloads/bundles/글-슬러그.zip`은 해당 글의 코드와 준비 파일, `README.md`를 담습니다. ZIP 안에서는 글 슬러그 폴더 하나를 사용합니다. 압축을 푼 뒤 이 폴더로 이동하면 안내한 상대 경로로 실행할 수 있습니다.

Python 3.12의 표준 라이브러리로 생성·검사합니다. 아래 명령 자체는 실습 코드를 실행하지 않습니다.

```bash
python3 scripts/build-practice-bundles.py
python3 scripts/build-practice-bundles.py --check
```

## 파일 목록

`src/data/practice-bundles.json`의 `posts`가 글별 구성을 정의합니다.

| 필드 | 용도 |
| --- | --- |
| `files[].source` | `public/downloads/` 아래 원본 파일 경로 |
| `files[].block` · `language` | 해당 글의 0부터 시작하는 코드 블록 번호와 언어. Bash 준비 예제를 그대로 포함할 때 사용 |
| `files[].name` | 압축 안의 파일 이름. 경로나 같은 이름을 중복해서 사용할 수 없음 |
| `requirements` | 실행에 필요한 운영체제와 도구 |
| `steps[].command` · `stdin` | 실행 명령과 선택적인 표준 입력 파일 |
| `steps[].exitCode` · `expected` | 예상 종료 코드와 출력 해석 |
| `notes` | 가상 입력 생성, 임시 경로 정리와 실행 조건 |
| `archive` | 생성한 ZIP의 경로·바이트 수·SHA-256과 포함 파일별 SHA-256 |

원본 파일 또는 본문 코드 중 한 종류만 파일마다 지정합니다. 생성기는 상대 경로의 범위, 파일 이름 중복, 공개 여부와 미래 발행일을 검사합니다. 디렉터리 전체를 수집하거나 실습 출력·개인 설정·생성된 키를 묶지 않습니다.

코드와 실행 안내가 같으면 ZIP 바이트도 같도록 내부 파일 시각·순서·권한과 저장 방식을 고정합니다. `--check`는 ZIP과 파일별 해시를 재계산해 원본과 다른 묶음이나 목록 밖의 ZIP이 있으면 실패합니다. 사이트의 자동 테스트에도 이 검사가 포함됩니다.

## 실행 환경

ZIP의 안내는 Linux/WSL의 Bash를 기준으로 합니다. 입력 파일을 코드가 생성하는 경우에는 가상 자료 준비 스크립트를 함께 제공합니다. 코딩 테스트의 `input.txt`와 gzip의 `sample.gz`는 ZIP에 들어 있습니다. 실제 시스템을 읽는 수집기가 함께 있더라도 기본 실행 안내는 가상 자료를 사용하는 명령입니다.

파일 다운로드는 글별 ZIP으로 제공합니다. 본문의 코드와 실행 기록은 함께 읽을 수 있습니다. 과거 실행 기록의 환경·날짜는 묶음 생성과 별개이며, 새로운 환경에서 실행한 값과 구별해 읽어야 합니다.
