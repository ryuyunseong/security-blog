## 결과와 근거 연결하기

점검 기록에는 항목, 확인한 대상의 범위, 관찰한 사실, 판단 기준과 한계를 나누어 적습니다. 확인하지 못한 상태를 양호로 바꾸지 않습니다.

## 최소 기록 표

아래 표는 실제 점검 결과가 아닌 작성 형식 예제입니다.

| 항목 | 내용 |
| --- | --- |
| 식별자 | LAB-001 |
| 확인 범위 | 로컬 실습 설정 파일 1개 |
| 관찰 | 필요한 설정값을 확인하지 못함 |
| 상태 | 추가 확인 필요 |
| 근거 | 익명화한 발췌문과 확인 날짜 |

## 공개 범위 검토

원문 로그와 설정 파일을 통째로 공개하지 않습니다. 사용자 이름, 호스트명, 자격 증명, 내부 주소가 발췌문에 남아 있는지 확인합니다.

이 예시는 특정 규정의 준수 여부나 실제 시스템의 안전성을 판정하지 않습니다. 적용 기준과 시스템 소유자의 확인이 필요한 항목은 별도로 남깁니다.
