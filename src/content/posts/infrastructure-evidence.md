## 점검한 대상과 적용 기준

어느 설정 파일을 읽었고 어떤 값이 있었는지부터 적습니다. 이어 적용한 기준과 판단을 쓰고, 자료를 얻지 못한 대상은 추가 확인 항목으로 남깁니다.

## 최소 기록 표

아래 표는 실제 점검 결과가 아닌 작성 형식 예제입니다.

| 항목 | 내용 |
| --- | --- |
| 식별자 | LAB-001 |
| 확인 범위 | 로컬 실습 설정 파일 1개 |
| 관찰 | 필요한 설정값을 확인하지 못함 |
| 상태 | 추가 확인 필요 |
| 근거 | 익명화한 발췌문과 확인 날짜 |

## 공개 범위 검토

원문 로그와 설정 파일을 통째로 공개하지 않습니다. 사용자 이름, 호스트명, 자격 증명, 내부 주소가 발췌문에 남아 있는지 확인합니다.

표에는 가상 자료만 들어 있습니다. 실제 보고서에 사용하려면 적용 기준과 시스템 소유자에게 확인할 사항을 채워야 합니다.
