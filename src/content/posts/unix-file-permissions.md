## 확인할 대상

GNU/Linux에서 로컬 파일 `./sample`의 소유자·그룹·권한을 조회하는 초안입니다. 실습용 파일을 준비한 뒤 아래 두 명령으로 현재 상태를 읽습니다. 파일 권한을 변경하는 명령은 포함하지 않았습니다.

## 읽기 전용 명령

```bash
ls -ld -- ./sample
stat -- ./sample
```

`ls -ld`는 대상 자체의 정보를 보여줍니다. `stat`으로 소유자와 권한 등 메타데이터를 함께 확인합니다. 명령의 출력에는 환경별로 사용자 이름과 경로가 포함될 수 있으므로 공개할 때 필요한 부분만 익명화해 기록합니다.

## 판단과 한계

소유자, 그룹, 기타 사용자의 권한을 차례로 읽습니다. 파일의 읽기·쓰기·실행 권한과 디렉터리의 탐색 권한은 의미가 다릅니다. 권한 비트만으로 실제 접근 가능 여부를 확정하지 않습니다.

접근 가능 여부를 조사하려면 상위 디렉터리 권한·ACL·마운트 옵션·보안 모듈 정책도 수집해야 합니다. 이 초안의 두 조회 명령은 그중 파일 메타데이터를 읽는 단계입니다.

공식 참고: [GNU Coreutils: 파일 권한](https://www.gnu.org/software/coreutils/manual/html_node/File-permissions.html).
